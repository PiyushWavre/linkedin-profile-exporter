# Code of conduct

## Our standard

This project welcomes constructive participation from people with different backgrounds and levels of experience.

Examples of behaviour that supports a productive community include:

- being respectful and specific when giving feedback;
- focusing criticism on code, design and behaviour rather than people;
- accepting that contributors may have different levels of familiarity with browser extensions;
- protecting personal information in bug reports and screenshots;
- acknowledging mistakes and correcting them.

Unacceptable behaviour includes harassment, discriminatory language, personal attacks, publishing another person's private information, deliberate disruption, or using project spaces to promote abusive or unlawful data collection.

## Scope

This code applies in project-managed spaces including issues, pull requests, discussions and other official collaboration channels.

## Enforcement

Project maintainers may edit, hide or remove contributions that violate these standards and may temporarily or permanently restrict participation when necessary.

Conduct concerns should be reported privately to **Piyush Wavre** using the contact method listed on the repository owner's GitHub profile. Security vulnerabilities should instead follow [SECURITY.md](SECURITY.md).
